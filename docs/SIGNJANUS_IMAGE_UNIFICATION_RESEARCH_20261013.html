9P0 优先候选

REPA 可以直接作为下一项监督实验

冻结教师：原始 GT pose → ST-GCN逐帧语义特征 → 对齐到每 4 帧一个 latent 的时间轴 → stop-gradient 目标。
可训练学生：带噪 latent＋时间＋文本条件 → 扩散 MLP中间 hidden → 新投影头 → 有效且受监督位置的 cosine 对齐。

保留当前 x0 扩散、DDIM 与 VAE；推理时不运行教师。只对齐 mT5 条件可作为另一项消融，应与带噪中间特征 REPA 区分。

当前 SignJanus：mT5 先产生条件，独立 MLP 在内层去噪；外层 MAR 分批补全。

原版 JanusFlow：每个 flow 步骤将带噪 latent 输入共享 LLM，再预测速度并作 Euler 更新。

建议先后次序

校准冻结 SLT 奖励 → REPA／RecA → Diffusion-DPO 对照 → 连续在线 RL 或重新推导 NFT → UniMRG 式反向辅助监督。

大规模 codec 重训、MoT、原生 flow、多轮反思需要更大改造。SLT 和 SLG 同时存在，不等于已经证明双向增益。
